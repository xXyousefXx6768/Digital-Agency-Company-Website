# Digital Agency Company Website

A professional, responsive website for a digital agency built using **React**, **Vite**, and **Tailwind CSS**.  
Designed to present agency services, portfolio work, about us section, and contact page in a clean and modern way.

## 🚀 Features

- **Multi-page architecture** using React Router (Home, Services, About, Contact)  
- **Responsive design** that adapts to desktop, tablet, and mobile  
- **Clean UI/UX** with Tailwind CSS utility-first styling  
- **Fast development & build** with Vite  
- **Scalable structure**: easy to extend with blog, testimonials, case studies, etc  
- **Contact form** (static or can be enhanced later to work with backend)  
- **Dark/light mode ready** (if implemented)

## 🛠 Tech Stack

- **React** — building the UI components  
- **Vite** — for fast bundling and dev server  
- **Tailwind CSS** — for styling  
- **JavaScript (ES6+)**  
- **React Router** — for client-side navigation
